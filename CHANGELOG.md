# Changelog

## [0.6.0](https://github.com/Dirnei/gaudiballz/compare/v0.5.2...v0.6.0) (2026-09-16)


### Features

* Every level has its own leaderboard, shown right in the solved dialog
* Move around the board with the keyboard
* A redesigned home page with community stats and your progress
* The game has its flask logo as its app icon


### Bug Fixes

* Win rate now counts restarts, so it means clears over tries

## [0.5.2](https://github.com/Dirnei/gaudiballz/compare/v0.5.1...v0.5.2) (2026-09-16)


### Features

* Finished columns are locked so you cannot pick them up by accident
* Flasks light up when you drag balls over a spot where they can go
* Level select is split into pages, newest levels first

## [0.5.1](https://github.com/Dirnei/gaudiballz/compare/v0.5.0...v0.5.1) (2026-09-16)


### Features

* New ball patterns: hearts, diner tiles, pig nose and camo


### Bug Fixes

* The move count no longer changes when you undo
* Smoother play on phones: the background glow is turned off there
